## Run
No installation is required.

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. For PDF: use **Print → Save as PDF**.

## Edit in VS Code
Open the extracted folder in VS Code. Main styling is in `css/style.css`; behavior is in `js/app.js`; lesson pages are under `units/`.
