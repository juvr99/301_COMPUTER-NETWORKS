MCA 301 -- Complete Last-Minute Revision

Unit I

  • Data communication: sender, receiver, message, medium, protocol.
  • Data flow: simplex, half-duplex, full-duplex.
  • Criteria: performance, reliability, security.
  • OSI: Physical, Data Link, Network, Transport, Session, Presentation, Application.
  • Impairments: attenuation, distortion, noise.
  • Delays: transmission = packet bits/rate; propagation = distance/speed.
  • Multiplexing: FDM, WDM, TDM.
  • Media: twisted pair, coaxial, fiber; radio, microwave, infrared.
  • Switching: circuit and packet.

Unit II

  • Framing; flow control.
  • Error detection: parity, checksum, CRC; correction: Hamming code.
  • ARQ: Stop-and-Wait, Go-Back-N, Selective Repeat.
  • Wireless LAN: IEEE 802.11; Bluetooth.
  • Virtual-circuit networks: Frame Relay, ATM; ATM cell = 53 bytes.

Unit III

  • IPv4 = 32 bits; IPv6 = 128 bits.
  • IPv6 base header = 40 bytes.
  • Dual stack = both IPv4 and IPv6; tunneling = one protocol carried inside another.
  • ARP resolves IPv4 to link-layer address; DHCP provides configuration; RARP is historical.
  • ICMP = IP control/diagnostics; IGMP = IPv4 multicast membership.
  • Distance vector: RIP; link state: OSPF.
  • DVMRP = multicast distance-vector family; MOSPF = multicast extension of OSPF concepts.

Unit IV

  • UDP header = source port, destination port, length, checksum.
  • TCP = reliable ordered byte stream.
  • TCP setup = SYN, SYN-ACK, ACK.
  • ACK = next sequence number expected.
  • Flow control = receiver protection (rwnd).
  • Congestion control = network protection (cwnd).
  • QoS = bandwidth, delay, jitter, loss, reliability.
  • CIA = confidentiality, integrity, availability.
  • Symmetric = shared secret; asymmetric = public/private.
  • Signature = private-key signing, public-key verification.
  • Authentication $\ne$ authorization.

Unit V

  • DNS = distributed hierarchical naming.
  • SMTP = mail transfer/submission; POP3 = mail retrieval.
  • FTP = file transfer with separate control/data concepts.
  • HTTP = request/response web protocol; HTTPS = HTTP over TLS.
