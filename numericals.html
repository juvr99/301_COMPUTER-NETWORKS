Step-by-step frameworks for the calculation-heavy Computer Networks questions.

High-Value Numerical Topics

UDP Checksum

Use 16-bit one’s-complement addition, end-around carry, then complement the final sum. Include the UDP pseudo-header where required.

Parity & Error Detection

For even parity, choose the parity bit so the total number of 1s is even. For odd parity, make the total number of 1s odd.

CRC

Append zeros equal to generator degree, perform modulo-2 division, and append the remainder.

TCP Sequence & ACK

ACK normally identifies the next byte expected. SYN and FIN consume one sequence number even though they carry no data.

Exam-Safe Solving Framework

  1. Write the given values clearly.
  2. State the formula/rule before calculating.
  3. Show intermediate steps, especially carries or remainders.
  4. Write units and the final answer.
  5. For protocol questions, draw the relevant header/flow diagram when appropriate.
Checksum reminder One’s-complement addition is not ordinary binary addition: any carry beyond 16 bits is wrapped around and added back to the low 16 bits.
